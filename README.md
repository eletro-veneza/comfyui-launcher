# 🚀 ComfyUI Launcher

![Uma imagem representativa do Launcher ComfyUI, mostrando as opções de CPU, GPU e execução.]

## 💡 Sobre o Projeto

O **ComfyUI Launcher** é uma aplicação GUI (Interface Gráfica de Usuário) dedicada e simplificada, desenvolvida por **Eletrônica Veneza @2025**, para revolucionar a gestão e execução de múltiplos ambientes do ComfyUI.

Cansado de gerenciar diferentes configurações de hardware (CPU vs. GPU), modos de execução ou interfaces gráficas separadas? Este launcher centraliza todas as opções em um único painel intuitivo. Nosso objetivo é garantir a máxima segurança, eficiência e performance, permitindo que você troque instantaneamente entre configurações complexas com apenas um clique.

Seja para testes de performance, desenvolvimento ou para iniciar um fluxo de trabalho pesado, o ComfyUI Launcher torna o processo rápido e sem retrabalho.

## ✨ Funcionalidades Principais

O ComfyUI Launcher oferece controle granular e rápido sobre sua instalação do ComfyUI, com as seguintes opções de execução:

*   **Modo de Execução Rápida:** Selecione a maneira como deseja iniciar o ComfyUI sem abrir o terminal.
*   **Seleção de Hardware:** Opções diretas para rodar o workflow tanto na **CPU** quanto na **GPU**, permitindo otimizar o uso dos recursos do seu computador.
*   **Controle de Interface:** Alterna facilmente entre visualizar a interface gráfica padrão do ComfyUI e o backend de desenvolvimento.
*   **Execução Global:** Opções de "Abrir em todas as janelas" ou "Executar tudo", ideais para automação de testes.
*   **Otimização:** Projetado para maximizar a eficiência dos recursos do seu sistema, garantindo que você obtenha a melhor performance possível.

## 🛠️ Pré-requisitos

Para rodar o launcher, você precisará ter instalado:

*   ✅ Python (versão compatível com o seu ComfyUI)
*   ✅ ComfyUI instalado no seu sistema.

## ⚙️ Como Usar

1.  **Inicia a Aplicação:** Execute o arquivo do launcher.
2.  **Selecione a Configuração:** Escolha a opção que corresponde à necessidade do seu script ou workflow (Ex: "Play GPU" se o seu projeto exigir aceleração de placa de vídeo).
3.  **Execute:** Clique no botão apropriado para iniciar o ComfyUI no modo selecionado.
4.  **Gerencie:** Utilize a interface para facilmente alternar entre os diferentes ambientes de execução (CPU, GPU, GUI normal, Backend, etc.).
